# project —— Vue3 练习项目

这是「Vue3 从零开始」学习材料的练习项目。配套的 13 份笔记在上一级目录的 `notes/` 里。

**先看总览和完整学习路线：[../README.md](../README.md)**

## 跑起来

```bash
npm install
npm run dev
```

然后打开终端里提示的网址（一般是 http://localhost:5173/ ）。

## 命令

| 命令 | 作用 |
| --- | --- |
| `npm run dev` | 启动开发服务器（平时就用这个） |
| `npm run build` | 打包成可以部署的文件，产物在 `dist/` |
| `npm run preview` | 本地预览打包结果 |

## 你要动手改的地方

`src/views/` 目录下每一章对应一个 `.vue` 文件，那就是你的练习本。
